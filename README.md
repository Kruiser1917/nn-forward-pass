# Основы нейронных сетей — Практика: forward pass руками (`NumPy`)

Практическая работа по **Модулю 06 (Deep Learning), Тема 01**: полная ручная реализация прямого прохода (`forward pass`), функций активации (`ReLU`, `Sigmoid`, `Tanh`), численно устойчивого `Softmax`, функции потерь `Cross-Entropy` (`LogSumExp`) и аналитического обратного прохода (`backward pass`) с проверкой конечными разностями для двухслойного полносвязного перцептрона (`4 -> 6 -> 3`) на чистом `NumPy`.

## Архитектура вычислительного графа (`B = 5, D = 4, H = 6, C = 3`)

```text
X (5, 4) --> [ X @ W1 + b1 ] --> Z1 (5, 6) --> [ ReLU ] --> A1 (5, 6) --> [ A1 @ W2 + b2 ] --> logits (5, 3)
               W1: (4, 6)                                                   W2: (6, 3)            |
               b1: (6,)                                                     b2: (3,)              +--> stable_softmax --> probs (5, 3)
                                                                                                  +--> LogSumExp CE   --> mean_loss ()
```

Общее число обучаемых параметров: `4 * 6 + 6 + 6 * 3 + 3 = 51` (`24 + 6 + 18 + 3`).

## Содержание исследования (`nn_forward_pass.ipynb`)

1. **Постановка задачи и архитектура 2-слойного MLP (`4 -> 6 -> 3`):** генерация воспроизводимого мини-батча `X (5, 4)`, меток `y_true = [0, 2, 1, 0, 2]` и параметров `W1, b1, W2, b2` (`seed = 42`).
2. **Отдельный нейрон и полносвязный слой (`Z1 = X @ W1 + b1`):** сверка пошагового скалярного расчёта на чистом Python с векторизованным матричным умножением, разбор `NumPy broadcasting` `(5, 6) + (6,) -> (5, 6)` и конвенции хранения весов `weight.shape == (out_features, in_features)` в `PyTorch nn.Linear`.
3. **Функции активации (`ReLU`, `Sigmoid`, `Tanh`) и роль нелинейности:**
   - графики функций и их производных ($\max \sigma'(z) = 0.25$ против единичной производной `ReLU` при $z > 0$);
   - применение `ReLU` к базовому батчу (`17` из `30` предактиваций $\le 0$ переходят в `0`);
   - алгебраическое и численное доказательство коллапса двух линейных слоёв без активации в один слой `W_eff = W1 @ W2 (4, 3)`, `b_eff = b1 @ W2 + b2 (3,)` (`15` эффективных параметров вместо `51`, `max |diff| < 1e-15`);
   - двумерный эксперимент на концентрических кольцах (`N = 240`, архитектура `2 -> 16 -> 2`): линейный коллапс без активации (`Mean CE = 0.6927`, `Accuracy = 53.75%`) против замкнутого кусочно-линейного контура с `ReLU` (`Mean CE = 0.0191`, `Accuracy = 100.00%`).
4. **Forward pass до `logits` и численно устойчивый `Softmax`:** демонстрация переполнения `naive_softmax([1000, 1001, 999]) -> nan`, реализация сдвига на построчный максимум `stable_softmax` и сверка со `scipy.special.softmax`.
5. **Функция потерь `Cross-Entropy`, `LogSumExp` и типичные ошибки API:**
   - расчёт базового `Mean CE = 1.3270` (выше уровня случайного угадывания $\ln 3 = 1.0986$ из-за уверенных ошибок, в частности на `sample_3`: `logits = [-0.2526, 1.7195, -0.8742]`, `probs = [0.1146, 0.8238, 0.0616]`, `CE = 2.1659`);
   - демонстрация численного `underflow` при `z = [-1000, 0, 0], y = 0` (`-ln(probs[0]) -> inf` против точного `1000.6931` через `LogSumExp`);
   - демонстрация ошибки двойного `Softmax` (максимальная вероятность ограничивается сверху числом $e / (e + 2) \approx 0.5761$, а минимально возможный `loss` застревает на `0.5514` вместо `0.0`);
   - устойчивая бинарная формула `bce_with_logits`.
6. **Диагностика `shape` всех 13 промежуточных тензоров** и разбор исключения `ValueError` при перепутанных осях матрицы весов `(6, 4)` вместо `(4, 6)`.
7. **Эксперимент с изменением весов и градиентным спуском:** верификация аналитических градиентов центральными конечными разностями (`max |diff| < 1e-9` по всем `51` параметру) и сравнение режимов весов.
